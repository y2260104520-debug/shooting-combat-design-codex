# Shooter Cases

这里保存射击战斗中的高价值案例。

适合记录：
- 武器结构性上位
- TTK / eTTK 偏差
- 后坐和命中率问题
- 3C 手感问题
- 技能转化效率
- 武器生态侵蚀
- 高低端差异
- 测试验证结果

## 推荐结构

- Context
- Combat Scenario
- Phenomenon
- Initial Hypothesis
- Analysis
- Decision
- Intervention
- Validation
- Result
- Candidate Rule
- Status

## 重要约束

不要只存最终参数。

案例价值在于保留：

为什么判断 → 为什么选这个干预点 → 哪些方案被排除 → 如何验证 → 得出了什么可复用规则

Candidate Rule 未经人工确认，不得自动写入 methodology/shooter/。
