# 示例项目约定：TPS PVPVE 大逃杀

> 这是示例，不代表必须照抄。用于让 Codex 有一份可直接读取的射击项目约定。

## 1. 项目类型

| 项 | 内容 |
|---|---|
| 项目名称 | 示例：Project BR-TPS |
| 类型 | TPS PVPVE 大逃杀 |
| 平台 | PC / 主机 |
| 视角 | 第三人称肩射 |
| 队伍规模 | 三人小队 |
| 复活规则 | 队友救援 + 局内复活资源 |

## 2. 战斗节奏与 TTK

| 项 | 内容 |
|---|---|
| 目标 TTK 档位 | 中等偏长 |
| 常规满血击杀时间 | 约 0.8-1.3s，实战常见 1.5s+ |
| 近距离击杀时间 | 更短，但要求承担贴脸风险 |
| 中距离击杀时间 | 主战斗区，要求枪械差异明显 |
| 远距离击杀时间 | 不鼓励稳定秒杀，偏消耗 / 压制 |
| 护甲 | 有 |
| 倒地状态 | 有 |
| 安全重置 | 中等，打药有风险 |

## 3. 主要交战距离

| 距离段 | 项目定义 | 主要武器 | 主要风险 |
|---|---|---|---|
| 0-10m | 房区贴脸、转角遭遇 | SMG、霰弹枪 | TTK 过短导致反应不足 |
| 10-30m | 主交战区 | AR、SMG、卡宾枪 | AR 过强会侵蚀 SMG |
| 30-60m | 架点、过点压制 | AR、DMR、连狙 | AR 过稳会侵蚀 DMR |
| 60m+ | 远距离消耗 | DMR、SR | 消耗过强会拖慢节奏 |

项目主要交战距离：10-50m。

## 4. 移动与 3C

| 项 | 内容 |
|---|---|
| 基础移动速度 | 中 |
| 横移速度 | 中 |
| ADS 移速惩罚 | 中 |
| 滑铲 | 有 |
| 位移技能 | 少量角色存在 |
| 空中精度惩罚 | 有 |
| 镜头 Kick | 中低，不能过度干扰跟枪 |

## 5. 枪械生态

| 武器类型 | 强势距离 | 主要优势 | 主要短板 | 生态边界 |
|---|---|---|---|---|
| SMG | 0-20m | 近距离 eTTK 稳、腰射强、机动高 | 25m 后衰减明显 | 不应稳定打赢中距离 AR |
| AR | 10-45m | 泛用、稳定、主武器 | 贴脸机动弱，远距离散布/衰减限制 | 不应覆盖 SMG 和 DMR |
| Carbine | 10-35m | 更灵活的中近距离步枪 | 远距压制弱，弹匣/衰减限制 | 不能成为轻量化上位 AR |
| DMR | 35m+ | 单发压制、远距换血 | 近距容错差 | 不能被 AR 中远距离稳定替代 |
| SR | 60m+ | 爆头威慑、远距离高价值 | 近中距离容错低 | 不能让对手无反制窗口 |
| LMG | 20-60m | 压制、弹匣、火力持续 | 机动差、换弹惩罚高 | 不能成为高容错 AR |
| Shotgun | 0-8m | 转角爆发 | 稳定性受距离限制 | 不能在 10m+ 稳定击杀 |

## 6. 后坐力与散布

| 项 | 内容 |
|---|---|
| 后坐力 | 固定主曲线 + 少量水平扰动 |
| 散布 | ADS 有动态散布，但需可学习 |
| 散布增长 | 按持续开火发数增长 |
| 散布恢复 | 停火后分段恢复，鼓励短点射 |
| 腰射 | 只服务 0-15m |
| 移动射击惩罚 | 中 |

## 7. 技能边界

技能应优先创造“信息 / 推进 / 控场 / 重置 / 救援”条件，不直接替代枪械击杀。

| 技能类型 | 强度边界 |
|---|---|
| 信息探测 | 提供方位 / 区域信息，不能长期透视 |
| 位移 | 创造角度或推进窗口，但释放后有开火限制或暴露风险 |
| 护盾 | 延长对枪或救援窗口，但需要被绕、被破、被爆炸物克制 |
| 治疗 | 提供续航，不应无脑拉长消耗战 |
| 控场 | 逼位 / 封路 / 打断架点，不应无风险覆盖所有入口 |

## 8. 主要风险

- AR 泛用性过强，侵蚀 SMG / DMR。
- 位移技能压缩反制窗口，导致高端局强势。
- 治疗和护盾叠加后拖长战斗，形成消耗流 Meta。
- 第三人称视角会强化卡视野收益，信息技能价值需要谨慎。
