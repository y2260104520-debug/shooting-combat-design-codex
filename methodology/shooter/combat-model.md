# Shooter Combat Model

## 核心观点

射击战斗结果不能只用理论伤害解释。

实际击杀链路：

发现目标 → 建立瞄准 → 开始输出 → 命中与跟枪 → 目标反应 → 继续兑现 → 击杀或脱离

## 理论 TTK

描述连续命中条件下的纸面效率。

TTK = (STK - 1) / RPS

## eTTK

实战有效击杀时间受以下因素影响：
- 首发延迟
- ADS 时间
- 命中率
- 空枪
- 后坐
- 散布
- 目标移动
- 掩体
- 换弹
- 技能
- 治疗 / 护甲
- 目标脱离

## 优势兑现链

武器优势 → 场景出现 → 玩家识别 → 玩家操作 → 命中转化 → 对手未完成反制 → 优势兑现

因此“拥有优势”不等于“能稳定兑现优势”。

## 分析原则

- 先看场景，再看数值。
- 理论强度和实战兑现分开。
- 平均值之外看命中率和玩家水平分布。
- 强度高可能来自数值，也可能来自低兑现门槛。
- 场景覆盖越宽，越需要明确支付成本。
