# Shooter Skill Analysis

## 1. 先定义战斗压力

技能先回答玩家缺什么：
- 接敌
- 脱离
- 信息
- 生存
- 输出窗口
- 控场
- 位置
- 资源
- 对抗特定目标

## 2. 解决方式

区分：

### 直接解决
技能本身完成伤害、控制、治疗、位移等主要结果。

### 创造条件
技能创造更好的射击位置、信息、命中窗口或时间窗口，让武器完成结果。

射击游戏中，若技能大量直接替代枪械完成击杀，要检查枪械价值是否被侵蚀。

## 3. 击杀窗口

判断技能是否：
- 缩短接敌时间
- 延长对手暴露
- 降低对手反击能力
- 提升己方命中率
- 改变交战距离
- 改变有效 TTK

## 4. 转化效率

技能触发 → 获得优势 → 玩家能否操作兑现 → 武器是否能完成转化

高端玩家往往能把位置、信息、精准类技能转化得更充分。

## 5. 风险与反制

至少检查一种明确成本或反制：
前摇、暴露、位移轨迹、资源、冷却、锁定、可打断、可规避、反技能。

如果收益覆盖多个场景，而风险又能被高手稳定消除，要警惕必选化。

## 6. Meta 检查

- 是否强化某一武器到结构性上位？
- 是否使某类交战变成唯一正确打法？
- 是否让对手只能用特定技能反制？
- 是否高端局收益远高于普通局？
