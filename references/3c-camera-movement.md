# 3C / 镜头 / 移动分析

## 1. 结论

射击游戏 3C（Character / Camera / Control，角色 / 镜头 / 操控）会直接改变枪械 eTTK（实战击杀时间）。移动越强、镜头越自由、身法越复杂，纸面 TTK 越不能代表真实强度。

---

## 2. 3C 对射击的影响链路

```text
输入响应
→ 角色速度变化
→ 目标可命中窗口
→ 镜头稳定性
→ 准星控制
→ 命中率
→ eTTK
```

---

## 3. 移动参数检查

| 参数 | 影响 |
|---|---|
| 基础移动速度 | 影响跟枪难度和脱战能力 |
| 横移速度 | 影响对枪命中率 |
| 加速度 / 减速度 | 影响身法可读性和手感粘滞感 |
| 跳跃高度 | 影响垂直瞄准压力 |
| 空中控制 | 影响跳射收益 |
| 滑铲速度 | 影响近战突破和转角压制 |
| ADS 移速 | 影响开镜对枪收益 |
| 冲刺出枪时间 | 影响遭遇战先手 |
| 位移后开火恢复 | 决定位移是否可直接转化击杀 |

---

## 4. 镜头参数检查

| 参数 | 影响 |
|---|---|
| FOV（视野） | 影响速度感、目标大小、周边信息 |
| Camera Lag（镜头滞后） | 影响移动顺滑和瞄准精确度 |
| Camera Shake（镜头震动） | 影响反馈和可读性，过强会干扰瞄准 |
| Weapon Sway（武器摆动） | 影响持枪质感和精度感知 |
| Recoil Camera Kick（后坐镜头冲击） | 影响射击反馈和压枪负担 |
| ADS FOV Scale（开镜视野缩放） | 影响目标识别和跟枪 |

---

## 5. 位移技能分析

位移技能强度由多个因素共同决定：

```text
位移距离
+ 位移速度
+ 方向可控性
+ 过程是否可开火
+ 落地后多久可开火
+ 是否改变散布/后坐
+ 是否暴露声音/特效
+ 是否可被打断
```

如果位移技能没有开火恢复惩罚，高端玩家会把它直接转化成击杀角度，强度会远高于低端局体感。

---

## 6. 高速战斗中的风险

| 风险 | 说明 |
|---|---|
| 目标窗口过短 | 玩家难以持续命中，枪械差异被掩盖 |
| 位移压缩反制 | 敌人看见技能但来不及处理 |
| 空中射击过强 | 地面枪线失去价值 |
| 镜头表现过重 | 手感爽但瞄准不可控 |
| ADS 移速过高 | 开镜成为无脑默认状态 |

---

## 7. 调优建议

| 目标 | 可调参数 |
|---|---|
| 降低跳射收益 | 空中散布、空中转身速度、落地恢复、跳跃高度 |
| 降低滑铲突破 | 滑铲速度衰减、滑铲中开火限制、滑铲结束硬直 |
| 强化移动爽感但不增强击杀 | 提升速度感/FOV，但延迟开火恢复或增加散布 |
| 降低高速目标难命中 | 降横移速度、增加加速度缓入、强化命中反馈 |
| 提升枪械反馈 | 镜头 Kick 与枪口动画同步，但避免遮挡准星 |
