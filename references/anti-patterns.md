# 射击战斗反模式自检

| 反模式 | 问题 | 修正方向 |
|---|---|---|
| 只看 TTK，不看 eTTK | 纸面平衡，实战失真 | 加入命中率、后坐、散布、移动分析 |
| AR 全距离泛用 | SMG / DMR 生态消失 | 用衰减、散布、机动、配件边界限制 |
| 技能无反制 | 对手只感到被系统惩罚 | 加前摇、声音、可摧毁物、范围提示 |
| 位移后立刻精准开火 | 高端玩家直接转化击杀角度 | 加落地恢复、散布惩罚、开火延迟 |
| 治疗/护盾无限拉扯 | 战斗拖长，击杀窗口消失 | 限制持续、资源、被打断条件 |
| 纯随机散布 | 玩家无法学习 | 使用可学习主方向 + 少量扰动 |
| 配件补齐所有短板 | 满改枪趋同 | 配件有取舍，不同时补精度/机动/弹匣 |
| 远程压制无代价 | 推进方无反制 | 增加视线遮挡、弹道/衰减、换弹/镜头惩罚 |
| 控场覆盖所有入口 | 进攻套路单一 | 缩范围、加生效延迟、增加绕路/破坏反制 |
| 技能只写效果不写场景 | 设计无法验证 | 写清楚距离、地图、时机、目标行为 |
| 平衡只按使用率 | 容易误判热门但不强 | 结合胜率、命中率、击杀距离、玩家段位 |
| 高端收益失控 | 比赛/高分段必选 | 增加操作风险、资源约束、反制窗口 |
| 新手收益过低 | 技能/枪没人理解 | 增加基础反馈、降低最低使用门槛 |
| 地图不支持武器定位 | 纸面生态无法出现 | 调整地图距离分布和资源点结构 |
