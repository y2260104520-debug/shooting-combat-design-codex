# Gunplay（枪械射击体验）总框架

## 1. 核心结论

射击手感不是单个参数决定，而是以下链路共同决定：

```text
发现敌人
→ 开镜/举枪
→ 首发命中
→ 持续命中
→ 后坐/散布控制
→ 目标移动与自身移动
→ 换弹/切枪/技能介入
→ 击杀/压制/撤离
```

任何枪械调优，都要判断问题发生在哪个环节。

---

## 2. Gunplay 关键指标

| 指标 | 作用 | 常见设计影响 |
|---|---|---|
| TTK（理论击杀时间） | 纸面杀伤效率 | 决定武器强度上限 |
| eTTK（实战击杀时间） | 玩家实际击杀效率 | 受命中率、后坐、散布、目标移动影响 |
| STK / BTK（击杀子弹数） | 伤害档位 | 影响爆头、护甲、衰减后的突变 |
| Hit Rate（命中率） | 实战兑现能力 | 决定纸面强度能否兑现 |
| Recoil（后坐力） | 输入学习成本 | 决定高手上限和压枪深度 |
| Spread / Bloom（散布 / 扩散） | 限制持续射击稳定性 | 决定点射、短连发、腰射边界 |
| Falloff（伤害衰减） | 控制距离生态 | 防止武器跨距离侵蚀 |
| Mobility（机动性） | 武器使用节奏 | ADS 移速、举枪、切枪、换弹 |
| Magazine（弹匣） | 容错和持续作战 | 影响多人战和压制能力 |

---

## 3. 射击体验的四层判断

| 层级 | 问题 | 例子 |
|---|---|---|
| 纸面层 | 这把枪理论强不强 | TTK 是否低于同类 |
| 操作层 | 玩家能否稳定兑现 | 后坐是否可控、散布是否过随机 |
| 场景层 | 地图是否给它优势距离 | 房区多则 SMG 强，长线多则 DMR 强 |
| 生态层 | 是否压缩其他武器选择 | AR 覆盖近中远导致 SMG/DMR 消失 |

---

## 4. 典型问题定位

| 玩家反馈 | 优先检查 |
|---|---|
| “这枪秒人太快” | BTK、RPM、爆头倍率、首发精度 |
| “这枪太稳” | 后坐曲线、水平扰动、ADS 散布、伤害衰减 |
| “这枪打不中” | 首发散布、后坐 Kick、枪口上跳、目标移动速度 |
| “近战没反应时间” | 近距 TTK、腰射强度、滑铲/跳射命中率 |
| “远距离全是刮痧” | 衰减、散布恢复、DMR/SR 生态是否成立 |
| “所有人都用步枪” | AR 强势距离是否过宽，地图主交战距离是否全在 AR 区间 |

---

## 5. 枪感调优优先级

优先从“玩家行为”反推参数，不要只盯单项数值。

```text
目标行为
→ 交战距离
→ 输入节奏
→ 命中率目标
→ 后坐/散布/衰减约束
→ 验证数据
```

例：想让 AR 在中远距离短点射，而不是无脑扫射：

- 不一定先降伤害。
- 可以增加连续开火散布增长。
- 可以让前 5 发稳定，后续水平后坐加剧。
- 可以提高停火恢复收益，让短点射 eTTK 更稳定。

---

## 6. 设计风险

| 风险 | 说明 |
|---|---|
| 纯随机散布过强 | 玩家无法学习，只觉得不受控 |
| 后坐过轻 | 高手和普通玩家差距可能转移到纯定位/先手 |
| TTK 只按纸面算 | 忽略第三人称、移动、掩体、网络、技能影响 |
| 枪械差异只靠伤害 | 容易造成强弱上下位，而不是生态差异 |
| 配件完全补短板 | 满改后所有枪趋同，失去武器生态 |
