# 地图交战空间

## 1. 结论

地图决定武器生态是否真实成立。纸面上 SMG / AR / DMR 分工清楚，但如果地图 80% 交火都发生在 10-35m，AR 就会天然受益。

---

## 2. 地图分析维度

| 维度 | 影响 |
|---|---|
| 交战距离分布 | 决定武器出场率和击杀占比 |
| 掩体密度 | 决定推进、架点、重置难度 |
| 视线长度 | 决定 DMR / SR 价值 |
| 室内比例 | 决定 SMG / Shotgun 价值 |
| 垂直空间 | 决定位移、信息、狙击点价值 |
| 热区 / 冷区 | 决定战斗节奏和转点选择 |
| 绕后路线 | 决定架点是否可反制 |
| 复活 / 补给点 | 决定战线持续性 |

---

## 3. 交战距离与武器生态

| 地图特征 | 受益武器 | 风险 |
|---|---|---|
| 大量房区 | SMG / Shotgun | 近战 TTK 过短，反应不足 |
| 中距离街区 | AR / Carbine | AR 泛用性过强 |
| 长视线平原 | DMR / SR | 远距离消耗拖慢节奏 |
| 高低差多 | SR / DMR / 位移角色 | 高点优势过强 |
| 掩体稀疏 | 远程武器 | 推进困难 |
| 掩体过密 | 近战武器 / 控场技能 | 架点价值下降 |

---

## 4. 热区 / 冷区

好的地图不一定全程高强度。冷区可以提供：

- 转点选择。
- 战斗节奏呼吸感。
- 长距离武器发挥空间。
- 侧翼路线。
- 战术复位机会。

但冷区不能完全无价值，否则玩家不会进入。

---

## 5. 技能与地图

| 技能类型 | 依赖地图条件 |
|---|---|
| 信息探测 | 掩体、室内、视野遮挡越多越强 |
| 位移 | 高低差、断点、侧翼路线越多越强 |
| 控场 | 窄口、房门、桥梁、通道越多越强 |
| 护盾 | 开阔地过点、救援点越多越强 |
| 治疗 | 可重置掩体越多越强 |

---

## 6. 地图验证问题

1. 每类武器是否有稳定触发强势距离的空间？
2. 主交战距离是否过度集中？
3. 架点是否有绕路、投掷物、技能反制？
4. 近战区域是否足够，但不强迫所有人近战？
5. 远距离视线是否有收益，但不会拖慢整体节奏？
6. 热区是否有战斗价值，冷区是否有转点价值？
