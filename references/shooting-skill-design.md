# 射击技能设计方法

## 1. 核心结论

射击游戏里的技能不应只问“效果酷不酷”，而要问：

```text
这个技能解决什么战斗压力？
它是直接解决问题，还是创造解决条件？
它如何帮助玩家兑现枪械优势？
敌人在哪里反制？
```

---

## 2. 技能定位分类

| 类型 | 解决的压力 | 常见风险 |
|---|---|---|
| 信息 | 不知道敌人位置 / 不敢推进 | 长时间透视导致对手无博弈 |
| 位移 | 无法接近 / 无法脱战 / 无法换角度 | 压缩反制窗口，高端收益过高 |
| 控场 | 敌人架点 / 通道被卡 | 泛用封锁导致推进套路单一 |
| 护盾 | 过点、救援、换弹窗口不足 | 堆叠后拖长战斗 |
| 治疗 | 战后续航 / 战中重置 | 消耗流 Meta，击杀窗口被稀释 |
| 爆发 | 缺少破局手段 | 替代枪械击杀，挫败感强 |
| 召唤/无人机 | 多线程信息或功能 | 本体风险不足，收益过稳定 |
| 反制 | 针对特定技能/状态 | 过窄没人选，过宽压制生态 |

---

## 3. 技能成立条件

一个技能成立，至少满足：

1. 有明确战斗压力。
2. 有稳定触发场景。
3. 有释放成本或风险。
4. 有敌方可观察反馈。
5. 有反制窗口。
6. 有高低端差异，但不至于高端独占收益。
7. 不让同定位技能全部失业。

---

## 4. 技能与 TTK 的关系

| TTK 环境 | 技能价值变化 |
|---|---|
| 短 TTK | 信息、闪光、逼位、打断架点价值高，因为博弈更多发生在交战前 |
| 中 TTK | 推进、护盾、治疗、控制都容易成立，但要防止过度消耗 |
| 长 TTK | 位移、续航、持续控制价值上升，技能更容易影响交战中拉扯 |

---

## 5. 技能设计检查表

| 检查项 | 问题 |
|---|---|
| 压力 | 玩家为什么需要这个技能？ |
| 场景 | 哪些地图/距离/局势下最强？ |
| 兑现 | 技能如何转化为击杀、推进、救援、重置？ |
| 风险 | 释放时玩家损失什么？时间、位置、声音、视野、武器输出？ |
| 反制 | 敌人能提前看见、打断、躲避、破坏、绕开吗？ |
| 上限 | 高端玩家能多拿什么收益？ |
| 下限 | 新手能不能理解基本用法？ |
| 生态 | 是否替代同类技能？是否强迫必选？ |

---

## 6. 技能常用约束手段

| 约束 | 适用场景 |
|---|---|
| 前摇 | 高影响技能必须给敌人反应时间 |
| 声音提示 | 信息、位移、无人机类需要暴露存在 |
| 范围限制 | 防止跨场景泛用 |
| 持续时间 | 控制收益窗口 |
| 冷却 | 控制使用频率 |
| 资源消耗 | 防止无脑使用 |
| 本体硬直 | 让释放者承担风险 |
| 破坏物 | 给敌人明确反制目标 |
| 视野限制 | 防止无风险远程收益 |

---

## 7. 常见技能模板

### 信息探测

```text
释放 → 暴露自身/介质 → 扫描延迟 → 显示短时信息 → 信息衰减/消失
```

重点：信息价值不等于击杀价值。短 TTK 项目中，短时信息也可能非常强。

### 治疗无人机

```text
部署 → 搜索目标 → 建立治疗链路 → 持续治疗 → 离开范围/被打断/被摧毁 → 结束
```

重点：治疗技能本质是在延长交战或缩短战后恢复时间，需要防止消耗流。

### 位移技能

```text
输入 → 状态判断 → 起跳/冲刺 → 位移过程 → 落地/结束 → 武器恢复 → 冷却
```

重点：位移不是只看距离，还要看开火恢复时间、镜头、散布、落点可控性。

### 护盾技能

```text
部署 → 形成遮挡/减伤 → 承受伤害/持续时间衰减 → 被绕/被破/到期 → 消失
```

重点：护盾要明确是推进、救援、对枪还是重置，不同定位参数完全不同。
