# TTK / eTTK / STK 模型

## 1. 基础公式

```text
RPS = RPM / 60
BTK = ceil(目标有效生命值 / 单发有效伤害)
TTK = (BTK - 1) / RPS
```

注意：第一发命中发生在开火瞬间，所以 TTK 用 `BTK - 1`。

---

## 2. TTK 与 eTTK 的区别

| 概念 | 含义 | 受什么影响 |
|---|---|---|
| TTK（理论击杀时间） | 全部命中时的击杀时间 | 伤害、射速、BTK |
| eTTK（实战击杀时间） | 实际对局中的击杀时间 | 命中率、后坐、散布、目标移动、掩体、技能、网络 |

简化估算：

```text
eTTK ≈ (BTK / 命中率 - 1) / RPS
```

这只是粗估。真实 eTTK 还会受首发反应、开镜时间、换弹、目标脱战影响。

---

## 3. STK / BTK 档位

BTK 是射击平衡中最敏感的档位之一。

例：

| BTK | RPM 600 时 TTK |
|---|---|
| 3 发 | 0.2s |
| 4 发 | 0.3s |
| 5 发 | 0.4s |
| 6 发 | 0.5s |

同样 +1 发，对低 BTK 武器影响更大。因为：

```text
3 → 4：TTK 增幅 50%
5 → 6：TTK 增幅 25%
```

所以“全武器 BTK +2”并不是等比例削弱，会重塑武器生态。

---

## 4. 只动血量的风险

只提高基础血量，不动护甲，常见影响：

| 影响 | 说明 |
|---|---|
| 护甲占比下降 | 护甲相对价值被稀释 |
| 爆头收益可能变化 | 若爆头跨越 BTK 档位，收益会突然放大 |
| 高射速武器可能受益 | Miss 后补枪更平滑 |
| 低射速高伤武器可能受损 | 每多一发带来更大时间惩罚 |
| 技能伤害价值变化 | 固定伤害技能可能变弱 |
| 治疗/护盾价值变化 | 战斗时间拉长，续航技能价值上升 |

---

## 5. TTK 调整流程

```text
明确目标：偏快还是偏慢
→ 确认问题距离：近 / 中 / 远
→ 找到问题武器和 BTK 档位
→ 判断是纸面 TTK 还是 eTTK 过强
→ 选择调整手段
→ 检查爆头、护甲、技能、地图影响
→ 做灰度验证
```

---

## 6. 调整手段对比

| 手段 | 优点 | 风险 |
|---|---|---|
| 提高血量 | 全局简单，感知明显 | 牵动全部武器、技能、护甲 |
| 降低伤害 | 精准控制单武器 | 可能破坏 BTK 档位 |
| 降低射速 | 改变手感和节奏 | 音效、动画、反馈需同步 |
| 增加衰减 | 控制距离生态 | 近距问题解决不了 |
| 增加散布/后坐 | 控制 eTTK | 过随机会影响学习性 |
| 调整爆头倍率 | 控制高手收益 | 可能降低技巧奖励 |

---

## 7. 判断 TTK 偏快时的提问清单

1. 是所有距离都快，还是近距离快？
2. 是所有枪都快，还是个别枪快？
3. 是理论 TTK 快，还是玩家命中率过高导致 eTTK 快？
4. 是血量问题，还是爆头/护甲/技能叠加问题？
5. 拉长 TTK 后，治疗、护盾、位移技能是否变强？
6. 拉长 TTK 后，高端玩家是否更容易通过跟枪拉开差距？
7. 是否需要同步调整地图掩体和推进窗口？
