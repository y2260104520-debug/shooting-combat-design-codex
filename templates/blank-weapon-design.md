| 距离 | 伤害 | BTK | TTK | 说明 |
|---|---:|---:|---:|---|
| 0-10m |  |  |  |  |
| 10-30m |  |  |  |  |
| 30-60m |  |  |  |  |
| 60m+ |  |  |  |  |

公式：

```text
RPS = RPM / 60
BTK = ceil(目标有效生命值 / 单发有效伤害)
TTK = (BTK - 1) / RPS
```
